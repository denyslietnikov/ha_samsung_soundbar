# Project History

This project builds on MIT-licensed Samsung soundbar integrations by
Samuel Spagl, Piotr Machowski, Thierry Bourbon and other contributors.
Earlier versions wrapped the public SmartThings API. That historical origin
does not describe the current runtime: this fork now uses local RPC and optional
authenticated local OCF only.

The current focus is HW-Q800F with reliable typed readback and preserved Home
Assistant device/entity identity. Protocol acknowledgments alone do not establish
working stateful controls. See the repository README for current support and
field-test limitations. Original attribution and the MIT license are retained.
