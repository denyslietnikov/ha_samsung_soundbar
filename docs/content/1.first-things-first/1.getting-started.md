# Getting Started

## Install

Add `https://github.com/denyslietnikov/ha_samsung_soundbar` to HACS as an
Integration repository, install Samsung Soundbar and restart Home Assistant.
Manual installations use `custom_components/samsung_soundbar` in the HA
configuration directory. Home Assistant 2026.9.4 or newer is required.

## Connect Locally

1. Enable IP Control on the soundbar and make it reachable from Home Assistant.
2. Add Samsung Soundbar in Settings -> Devices & services.
3. Choose **Local only (RPC)** (`local_only`) or **Hybrid Local + OCF**
   (`hybrid_local_ocf`).
4. Enter the host and local HTTPS RPC port (normally 1516), timeout and
   certificate verification setting. The soundbar normally uses a local
   certificate that requires verification to be disabled.
5. Home Assistant checks RPC and stable physical identity metadata before saving.

The integration does not require an account sign-in. The model-only RPC
identifier is not a unique physical identity.

## Existing Entries

Do not remove/re-add the entry to change modes. Existing device/entity IDs,
history, custom names and the separate OCF credential Store are preserved.
Entries without a verified local host require local Reconfigure or Options;
the Local soundbar configuration required Repair opens that existing entry.
The integration does not guess an address or silently bind a different soundbar.

Only the exact obsolete EQ select and former Woofer +/- button registry rows
owned by the entry are removed. Dashboards using them need manual adjustment.

## Optional OCF

Hybrid can run RPC with a missing-credential warning. This does not mean OCF
is connected. Import an existing credential through the entry's Options;
successful import selects Hybrid Local + OCF. Advanced controls appear only
after authentication and validated local readback. Switching back to Local only
(RPC) retains the saved credential but does not use it.

Read the [credential and security guide](https://github.com/denyslietnikov/ha_samsung_soundbar#local-ocf-credentials)
before importing or forgetting a credential. Keep an encrypted external backup.
Never send credentials or whole phone backups in an issue or chat.
