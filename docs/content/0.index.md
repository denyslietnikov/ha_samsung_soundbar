# Samsung Soundbar

Local Home Assistant control for Samsung soundbars, focused on HW-Q800F.

- [Installation and local setup](/first-things-first/getting-started)
- [Controls and limitations](/features)
- [Reporting an issue](/first-things-first/issues-and-other-things)
- [Project history](/first-things-first/why-another-integration)

Both modes use local RPC. Hybrid Local + OCF adds validated audio controls only
when a saved credential authenticates and the required readback is available.
Hybrid without a credential remains RPC-only operation with a warning.

See the [repository README](https://github.com/denyslietnikov/ha_samsung_soundbar#readme)
for credential import, recovery, security and detailed protocol limitations.
